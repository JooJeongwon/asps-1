# 《오늘, 우리 중 한 명을 선택해》

여자 전학생인 주인공은 이름과 얼굴이 드러나지 않는다. 첫날 네 명을 차례로 알아가고, 공동 위기를 함께 해결한 뒤 마지막 밤 직접 한 명을 선택한다.

## 확정한 팀 역할

| 인물 | 실제 역할 | 이야기 속 인상 |
| --- | --- | --- |
| 정치훈 | PM | 생각을 움직임으로 바꾸는 추진력 |
| 박진환 | 백엔드 | 사람과 데이터 사이를 연결하는 문제 해결 |

| 남성수 | 발표 | 복잡한 내용을 차분하게 전하는 관찰력 |

## 사주 데이터가 이야기에 쓰이는 곳

- **정치훈 · 갑진 甲辰:** 갑진의 나무를 이야기의 모티프로 삼아, 팀이 함께 갈 방향을 세운다.
- **박진환 · 을해 乙亥:** 을해의 가지를 이야기의 모티프로 삼아, 흩어진 데이터와 사람을 잇는다.
- **주정원 · 경진 庚辰:** 경진의 금속을 이야기의 모티프로 삼아, 복잡한 화면을 명확하게 다듬는다.
- **남성수 · 무진 戊辰:** 무진의 땅을 이야기의 모티프로 삼아, 네 사람의 이야기가 설 자리를 만든다.

CUT 03에서 Supabase의 네 팀원 간 사주 점수 여섯 조합을 조회해 ‘우리 팀의 사주 노트’를 연다. 종합 궁합·MBTI·KAI 점수를 사주 점수로 대신 쓰지 않는다. 원점수로 순서를 정하고 화면에는 소수점 한 자리로 표시한다. CUT 16에서는 같은 회차의 점수와 최고 조합을 다시 언급한다. 데이터 조회 실패 시 점수를 만들지 않고 공통 이야기를 계속한다. 저장/불러오기와 되감기는 해당 회차의 데이터를 유지하며 새 회차는 다시 조회한다. 주인공의 사주나 생년월일은 설정하지 않는다.

역할은 사용자가 확정했다. MBTI·일주·KAI와 관심사 문구는 기존 프로젝트에서 가져왔으며, 사건·대사·감정과 캐릭터의 성격 묘사는 창작이다. 사주나 MBTI가 실제 성격·감정·연애 결과를 결정한다는 설정은 사용하지 않는다.
