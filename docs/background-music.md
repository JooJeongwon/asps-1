# 배경음악

- 곡: Sweet Cherry
- 제작: 사운드스프레이 Soundspray
- 요청 영상: https://www.youtube.com/watch?v=wefAT9LZ_BM
- 제작자 지정 출처 링크: https://youtu.be/2kdsec1iJXE
- 제작자가 영상 설명에 공개한 WAV: https://drive.google.com/file/d/1FgrkqHK2v9pQOdU4xZ3euTD3zcgf2quJ/view
- 배포 파일: `public/assets/audio/sweet-cherry.mp3` (원본 WAV를 128 kbps MP3로 변환)

영상 설명은 비상업적 이용에 출처 표기를 요구하며 사용 댓글도 남기도록 안내한다. 상업성 있는 대회나 공모전 등은 별도 문의 대상이다. 음량 패널에 제작자가 지정한 곡명·제작자·출처 링크를 표기한다.

게임과 팀 소개 페이지 우측 상단의 음악 버튼에서 소리를 켜고 끄거나 음량을 조절한다. 게임의 설정 화면에서도 같은 음량 패널을 열 수 있다. 기본 음량은 20%이고, 첫 사용자 조작 때 재생한다. 사용자 설정은 로컬 저장소에 보관한다. 숨겨진 탭에서는 일시정지한다. 게임 저장/불러오기와 독립적으로 동작하며 브라우저 저장소가 차단되어도 재생할 수 있다.
